# Spy Language
Spy Programming Language Engine & Compiler — GPLv3

Fast, self-hosting language that compiles to C/C++/LLVM IR.

## Build
```bash
cmake -B build && cmake --build build
```

## Run
```bash
./spy_compiler_linux examples/hello.spy -o hello
```
